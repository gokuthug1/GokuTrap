Deployment Architecture

Where is GokuTrap Installed?

Understand the filesystem structure, installation directories, and execution lifecycle on your PC.

1

Single-File Executable

GokuTrap ships as a self-extracting single-file binary (GokuTrap.exe). It requires zero third-party installers or dependencies.

dotnet publish GokuTrap/GokuTrap.csproj -c Release
Direct Download GokuTrap.exe
2

Standard Target Location

When run, GokuTrap automatically registers and deploys its files into the per-user Local AppData directory:

%LocalAppData%\GokuTrap

Full path: C:\Users\<Username>\AppData\Local\GokuTrap

3

CLI Launch Options

GokuTrap supports explicit command-line switches for scripted deployments and quick navigation:

GokuTrap.exe -menu

Use -preferences for settings, -uninstall for clean removal.

Knowledge Base

Frequently Asked Questions

Find answers to common questions about installation, account safety, and modifications.

Is GokuTrap safe to use and can I get banned?

GokuTrap is an external bootstrapper and launcher. It does not inject DLLs, execute arbitrary bytecode, or manipulate the Roblox process memory. FastFlags are native configuration parameters officially provided by Roblox's game engine. Client mods merely override local asset files before the engine starts.

Where are my configuration and FastFlag files stored?

All settings are located in %LocalAppData%\GokuTrap\Settings.json. FastFlags are written directly to ClientSettings\ClientAppSettings.json within your active Roblox deployment folder under %LocalAppData%\GokuTrap\Versions\.

How do I migrate my existing settings from Bloxstrap or Fishstrap?

GokuTrap includes automated migration logic. If an existing Bloxstrap or Fishstrap directory is detected in %LocalAppData% during initial setup, an import prompt allows transferring your FastFlags, themes, and client mods in one click.

How do I uninstall GokuTrap cleanly?

You can run GokuTrap.exe -uninstall or uninstall it from Windows Settings > Apps > Installed Apps. It cleanly removes all registered shortcuts, registry keys, and temporary files.
